# Video production archive

These scripts record how the narrated application walkthrough was produced. They expect the original Hackathon workspace layout, captured browser screenshots, per-scene audio and the original map/query sessions. They are not needed to run the localization application. See the application README for the supported entrypoints. The model and private runtime environment used to generate the voice are not committed; upstream model and voice provenance are recorded in voice_provenance.json.
