# 手机拍照定位

手机端是现有程序的浏览器界面。Windows 电脑保存地图、运行 COLMAP；手机拍照、上传并查看结果，不需要安装手机应用。照片在电脑上保存和处理，不上传到云端。

## 第一次使用

1. 在电脑主程序打开要使用的地图项目。手机服务启动时会读取该项目，之后在桌面切换项目不会自动改变已经运行的手机服务；需要停止并重新启动手机服务。
2. 双击本目录的“启动手机端.cmd”。保留服务窗口，关闭它就会停止服务。它会自动打开电脑预览，同时打印 `http://192.168...:8765/?token=...` 这样的手机链接。不要在服务已经运行时再开第二份。
3. 手机和电脑连接同一 Wi-Fi。把带访问码的完整链接发送到自己手机，在 Safari 或 Chrome 打开。手机不能用链接中的 `127.0.0.1`，应使用电脑显示的局域网地址。每次重启访问码会变化，以新链接为准。
4. 若 Windows 防火墙提示允许 Python 通信，可在自己信任的私人网络允许。若手机连接不上，先检查两端网络、电脑服务窗口和链接，排除访客 Wi-Fi 或校园网的设备隔离。程序没有自动更改防火墙设置。连接信息也保存在 `mobile_connection.json`。

## 拍照、上传与查看

点击底部“拍照定位”。支持的手机浏览器会调起后置系统相机；部分设备可能显示照片选择菜单，可选择拍摄。拍完确认照片后，网页自动转换为最长边2400像素的 JPEG、上传并开始定位。也可以点击“从相册选择”。不用手动复制照片到电脑。

等待时显示处理阶段，按钮暂时禁用，避免重复提交。成功后显示附近区域、地图标记、拍摄方向和匹配参考画面。失败会说明原因，不产生替代坐标。一次定位是单张照片拍摄时的位置，走动后需要重新拍照。本版没有实时跟踪或多照片位姿融合。

当前真实地图使用旧位置标定及独立方向标定，显示橙色“估计位置”与红色方向箭头，位置仍需现场验证。位置标定通过时显示红色“照片位置”，才能从该位置规划路线。只有方向没有位置时，箭头在独立方向框显示。地图可以拖动，并使用右上角按钮缩放、恢复全图。

“周围的重要地点”来自电脑端手工标注。点击地点可聚焦到地图位置；当前位置通过标定时，点击可计算已标通路上的路线。不能确定出发位置时仍展示所有已标通路，但不会假称这些线段是从你当前位置出发的推荐路线。米数只有在地图已填写真实标尺时显示。

“查看电脑上最近一次定位”用于回顾，界面会明确显示它是历史照片，不能当作实时位置。

## 建议怎样拍

- 先拍1张。使用后置主摄、普通照片模式、1×，尽量保持与建图时相同的镜头。不要用人像模式、超广角、美颜或数字变焦。
- 手机保持直立，镜头大致水平，站稳后拍摄。画面包含较完整的门框、窗框、标牌、墙角和固定家具，避免仅对着白墙或近距离小物件。
- 避免镜面反光、严重逆光、运动模糊、大片遮挡和与建图时变化很大的场景。程序匹配的是已有地图的视觉特征，不是通过认识“这是门”就确定你的位置。
- 定位失败时，先在同一站位换一个能看到更多固定环境的方向再拍；也可以走一步后重新拍摄。不要只是原地连拍同一画面。每张照片独立定位，成功结果对应那张照片的位置，不会平均为一个虚构位置。

## 相机自动控制的实际范围

同一 Wi-Fi 的普通 HTTP 连接默认使用系统相机入口。网页不能保证强制指定手机的物理焦距、主摄镜头、快门、曝光或自动连拍张数，系统相机参数需用户调整。

拍摄指南另有“尝试网页相机预览”。仅在 HTTPS 或电脑 localhost 等安全上下文且浏览器支持时可用，需要用户授权相机。程序请求后置摄像头和较高分辨率；若设备开放 zoom 且支持数值1，会尝试请求该倍率，并显示是否受支持。这个数值不保证等于手机原生相机的主摄1×。点击快门后拍1张并自动上传，关闭相机后停止摄像头。手机普通局域网 HTTP 链接不支持这个预览，因此不会把它作为必须使用的流程，也没有绕过浏览器权限。

若今后需要跨品牌严格固定镜头、焦距和连拍流程，应再开发原生 Android/iOS 客户端。当前单张照片定位不要求先完成复杂的多张采集流程。

## 数据与测试

`mobile_uploads` 保存手机上传的规范化照片；定位输出仍在地图项目 `queries`，与桌面程序使用同一格式。手机端不改动 COLMAP 原模型或地图标注。接口只服务启动时选择的一个项目，访问码保护地图和照片接口，不提供任意本地文件读取。

已通过真实照片的网页选择、浏览器 JPEG 转换、上传、COLMAP 定位和结果展示。390像素宽界面与拍摄引导完成浏览器检查，无横向溢出。21项测试通过，包括接口访问码、目录越界拒绝、无效图片、处理任务互斥、失败时无坐标、估计位置禁用路线，以及每个客户端使用自己的定位结果规划路线。尚未完成不同真实手机型号、校园网及手机系统相机的现场测试，需要你在手机上试拍确认。

浏览器能力参考：[系统相机入口](https://developer.mozilla.org/en-US/docs/Web/HTML/Reference/Attributes/capture)、[网页相机的安全上下文与权限](https://developer.mozilla.org/en-US/docs/Web/API/MediaDevices/getUserMedia)、[设备变焦能力](https://developer.mozilla.org/en-US/docs/Web/API/MediaStream_Image_Capture_API)。


连接故障排查：手机链接必须包含 ?token= 后的访问码。程序现在保留访问码，重启后原链接仍可使用（电脑 IP 不变时）。同一端口只允许启动一份手机服务；重复双击会提示端口已占用，不会覆盖已有链接。页面会区分访问码无效和网络连接失败，提供重新连接按钮。若需要更换地图项目，先关闭旧服务窗口再重新启动。mobile_access.json 存放本机访问码，不要分享源码时一并发送。
